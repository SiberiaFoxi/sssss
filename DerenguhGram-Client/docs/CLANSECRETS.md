# ClanSecrets — окно диагностики и собственных данных

`ClanSecrets` — отдельное окно (Qt `QDialog` на ПК, `Activity` на Android), доступное
из главного меню. Назначение: дать пользователю прозрачность над **его собственным**
клиентом и данными.

## Вкладки / разделы

### 1. Логи
* Сетевые соединения (DC, SNI, статус рукопожатия DerenguhProto).
* Ошибки транспорта и прокси.
* Версия клиента и текущий статус прокси.
* Кольцевой буфер (ПК: `QPlainTextEdit.setMaximumBlockCount(5000)`; Android: обрезка
  строки до 64 КБ) — память ограничена.

Источники записей: `ProxyTransport` (ПК) / `DerenguhTunnel`/`DerenguhLocalBridge`
(Android) вызывают `appendLog(...)` на этапах: TCP-connect, ClientHello, ServerHello
verify, control/ack, ready, ошибки.

### 2. Кэш
* Путь к папке кэша и кнопка «Открыть» (`QDesktopServices` / `Intent.ACTION_VIEW`).
* Список файлов **вашего** кэша.
* Расшифровка: медиафайлы кэша обычно лежат как есть; сообщения в `tdata` зашифрованы
  **локальным ключом сессии**. Расшифровка выполняется только для ВАШЕГО аккаунта через
  Storage-слой клиента:
  - ПК: `Storage::Account` / `Storage::LocalKey` (ключ доступен в активной сессии).
    Используйте существующие `Storage::FileLoader`/`Cache` API, не пишите свой крипто-слой.
  - Android: `MessagesStorage` / `MediaController` — файлы уже расшифрованы при доступе
    из активного аккаунта; показывайте их через штатные пути.
* Окно показывает, какие файлы были зашифрованы (метаданные), и открывает уже
  расшифрованный контент вашего аккаунта. Чужие ключи не извлекаются.

### 3. ClanSecrets (папка экспорта)
Сохраняется **только контент, который вам разрешено хранить**:
* обычные фото/видео/файлы без таймера и без запрета сохранения;
* медиа, которые отправитель прислал как постоянные.

## Почему нет скрытого сохранения самоуничтожающихся медиа

Самоуничтожающиеся и «одноразовые» сообщения — это защита, которую **отправитель явно
включил**. Скрытый перехват до истечения таймера:
* нарушает выраженное согласие отправителя на эфемерность;
* может способствовать несанкционированному удержанию приватного/интимного контента.

Поэтому мод **не** перехватывает такой контент. Вместо этого реализована уважающая
согласие альтернатива:

### «Запросить постоянную копию»
Кнопка открывает чат с отправителем и черновик вежливого запроса:
> «Привет! Можешь прислать это фото/видео ещё раз без таймера? Хочу сохранить.»

Решение остаётся за отправителем. Интеграция:
- ПК: открыть `History` отправителя и положить текст в поле ввода
  (`Window::SessionController::showPeerHistory` + `HistoryView::Field::setText`).
- Android: `ChatActivity.openChat(...)` с `messageText` extras (черновик).

Если отправитель согласен и присылает постоянную копию — она сохраняется в папку
`ClanSecrets` обычным путём, без обхода каких-либо защит.

## Память и приватность окна

* Логи ограничены по размеру; кэш-листинг ленивый.
* Окно не отправляет данные наружу; это локальный инструмент.
* Доступ к кэшу — только в рамках авторизованной сессии пользователя.
